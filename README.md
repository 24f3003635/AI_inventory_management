# Edge-AI Retail Intelligence Platform 🛒

This project is an AI-powered retail analytics system developed for **Smart India Hackathon 2026 (Problem Statement ID26179)**. It leverages on-device Edge AI to deliver real-time shopper analytics, automated inventory monitoring, and proactive queue management. 

Designed specifically for the diverse Indian retail sector—from neighborhood pharmacies to large supermarkets—the platform processes video streams locally. This approach ensures low-latency decision-making, protects shopper privacy, and maintains uninterrupted operations even in areas with constrained internet connectivity.
